# RateStats_Portable 维护文档（文件职责：直观版）

## 0) 全脚本职责（先看这个）

> 这一节先把常用脚本全部说明白；后面章节再讲链路和增删改步骤。

- `market_rate_data_generator.py`：MarketRateData 入口脚本，触发主流程。
- `generate_rainbow_from_market.py`：彩虹表入口脚本，触发彩虹回填流程。
- `bank_all_promo_rates.py`：总编排脚本，串起参数、抓取、建表、输出。
- `bank_cli_parser.py`：定义所有命令行参数及默认行为。
- `bank_cli_fetch_params.py`：把 CLI 参数映射成 `fetch_and_extract()` 入参。
- `bank_cli_url_config_applier.py`：把 URL 配置文件覆盖到 CLI 参数对象（CLI 显式值优先）。
- `bank_xlsx_out_resolver.py`：统一解析输出 Excel 路径与命名。
- `bank_fetch_and_extract.py`：抓取与提取总入口，聚合各银行 payload。
- `bank_constants.py`：集中维护抓取与表结构共用常量。
- `bank_excel_data_builder.py`：把 payload 转为标准 DataFrame。
- `bank_excel_template_writer.py`：按模板与规则把 DataFrame 写入 Excel。
- `bank_excel_style_helpers.py`：提供 Excel 样式辅助函数。
- `bank_output_stage.py`：统一执行落盘输出（Excel/JSON/stdout）。
- `generate_rainbow_from_bank.py`：读取 MarketRateData 并回填彩虹表模板。
- `bank_safety.py`：提供异常兜底与安全调用包装。
- `url_sources.py`：内置 URL 常量来源。
- `url_defaults.py`：组织默认 URL 参数字典。
- `url_config_loader.py`：读取 `assets/url_params.xlsx|json` 并解析为可用配置。
- `url_args_override.py`：把外部 URL 配置覆盖到 argparse 对象。
- `url_key_aliases.py`：维护 URL 友好键到 `dest` 的映射关系。
- `01_首次安装依赖.bat`：安装运行所需依赖。
- `02_一键生成Excel.bat`：一键生成 MarketRateData。
- `03_一键生成Market+彩虹表.bat`：一键生成 MarketRateData 与彩虹表。

### 0.1 高频改动与典型误改现象（速查表）

| 脚本 | 高频改动 | 误改后典型报错/现象 |
|---|---|---|
| `bank_cli_parser.py` | 新增/下线参数、调整默认值 | 参数不识别（`unrecognized arguments`） |
| `bank_cli_fetch_params.py` | 参数映射到抓取函数 | `unexpected keyword argument` / 缺参异常 |
| `url_key_aliases.py` | 新增 alias 与白名单 | 配置文件写了但不生效（静默回退默认值） |
| `url_defaults.py` | 默认 URL 字典增删 | 运行时 URL 为空或走错站点 |
| `url_config_loader.py` | 解析 xlsx/json 字段格式 | 配置加载失败、键值类型异常 |
| `url_args_override.py` | 覆盖逻辑增删 | CLI 与配置优先级错乱 |
| `bank_fetch_and_extract.py` | 接入新站点、修改提取入口 | 抓取成功但 payload 为空，或全流程无数据行 |
| `bank_excel_data_builder.py` | payload 字段映射、列顺序 | Excel 列错位、关键列全空、行被误过滤 |
| `bank_excel_template_writer.py` | sheet 规则、写入起始区、过滤规则 | sheet 缺失/多余、数据写到错误区域 |
| `bank_output_stage.py` | 输出类型与落盘流程 | 文件未生成、stdout 输出与预期不一致 |
| `generate_rainbow_from_bank.py` | 源文件定位、匹配规则、回填规则 | 彩虹表匹配不到银行/档位、回填为空 |
| `bank_safety.py` | 异常兜底策略 | 本应降级但直接中断，或异常被过度吞掉 |
| `bank_xlsx_out_resolver.py` | 输出路径命名规则 | 输出路径异常、文件名重复覆盖 |
| `assets/MarketRateData_template.xlsx` | 列布局、sheet 结构 | 写表错位、样式异常、部分列丢失 |
| `assets/url_params.xlsx` / `assets/url_params.json` | URL 配置项维护 | URL 未覆盖默认值、配置键失配 |

### 0.2 按报错关键词反查脚本（先查顺序）

| 报错关键词/现象 | 先查这些文件（按顺序） |
|---|---|
| `unrecognized arguments` | `bank_cli_parser.py` -> `02_一键生成Excel.bat` / `03_一键生成Market+彩虹表.bat` |
| `unexpected keyword argument` | `bank_cli_fetch_params.py` -> `bank_fetch_and_extract.py` |
| URL 配置写了不生效 | `url_key_aliases.py` -> `url_args_override.py` -> `url_config_loader.py` |
| 配置解析失败（xlsx/json） | `url_config_loader.py` -> `assets/url_params.xlsx` / `assets/url_params.json` |
| 运行成功但没有数据行 | `bank_fetch_and_extract.py` -> `bank_excel_data_builder.py` |
| Excel 列错位/关键列为空 | `bank_excel_data_builder.py` -> `assets/MarketRateData_template.xlsx` -> `bank_excel_template_writer.py` |
| sheet 缺失/多余 | `bank_excel_template_writer.py` -> `assets/MarketRateData_template.xlsx` |
| 输出文件未生成/路径异常 | `bank_xlsx_out_resolver.py` -> `bank_output_stage.py` |
| 彩虹表匹配不到银行或档位 | `generate_rainbow_from_bank.py`（`resolve_latest_source()`、匹配函数） |
| 彩虹表来源文件找不到 | `generate_rainbow_from_bank.py` -> `bank_output_stage.py`（确认 MarketRateData 是否落盘） |
| 异常没有被兜底或被吞掉 | `bank_safety.py` -> `bank_output_stage.py` |
| 样式异常（底色/边框/居中） | `bank_excel_style_helpers.py` -> `bank_excel_template_writer.py` |

### 0.3 5 分钟排障流程图（固定顺序）

> 目标：先判断“卡在哪一层”，再进对应脚本，避免来回跳文件。

1. **参数层先过**
   - 现象：启动即报参数错误（如 `unrecognized arguments`、缺参）。
   - 先查：`bank_cli_parser.py` -> `bank_cli_fetch_params.py` -> `02_一键生成Excel.bat` / `03_一键生成Market+彩虹表.bat`。

2. **确认 URL 配置是否真的生效**
   - 现象：运行了但抓错站点、仍走旧 URL、配置改了无效。
   - 先查：`url_key_aliases.py` -> `url_config_loader.py` -> `url_args_override.py` -> `url_defaults.py`。

3. **抓取层是否产出 payload**
   - 现象：程序无报错但没有数据行。
   - 先查：`bank_fetch_and_extract.py`（请求与提取返回结构）。
   - 再查：`bank_constants.py`（关键常量是否被误改）。

4. **DataFrame 转换层是否对齐**
   - 现象：有数据但列为空、列错位、行数异常。
   - 先查：`bank_excel_data_builder.py`（字段映射、列顺序、缺省补齐、过滤条件）。

5. **模板写入层是否正确**
   - 现象：sheet 缺失/多余、写入错区域、样式异常。
   - 先查：`bank_excel_template_writer.py`。
   - 联动：`assets/MarketRateData_template.xlsx`、`bank_excel_style_helpers.py`。

6. **输出与落盘是否完成**
   - 现象：控制台看似成功，但文件未生成或路径异常。
   - 先查：`bank_xlsx_out_resolver.py` -> `bank_output_stage.py`。

7. **彩虹表链路单独排**
   - 现象：MarketRateData 正常，但彩虹表匹配不到银行/档位/来源文件。
   - 先查：`generate_rainbow_from_bank.py`（`resolve_latest_source()`、匹配函数、模板识别逻辑）。

8. **最后检查兜底是否掩盖真实错误**
   - 现象：无明显报错但结果缺失，或异常被吞。
   - 先查：`bank_safety.py`，确认降级策略是否过度。

## 3) 文件职责速查（按执行阶段）

### 3.1 入口与总编排

- `market_rate_data_generator.py`
  - MarketRateData 入口（调用 `bank_all_promo_rates.main()`）。
- `generate_rainbow_from_market.py`
  - 彩虹表入口（调用 `generate_rainbow_from_bank.main()`）。
- `bank_all_promo_rates.py`
  - 主编排：参数解析 -> 抓取汇总 -> DataFrame 构建 -> 输出阶段。

### 3.2 参数与 URL 配置链路

- `bank_cli_parser.py`
  - 定义 CLI 参数（URL、开关、输出路径、格式控制）。
- `bank_cli_fetch_params.py`
  - argparse 参数 -> `fetch_and_extract()` 入参映射。
- `bank_cli_url_config_applier.py`
  - 将 URL 配置应用到 CLI 默认值（显式 CLI 参数优先）。
- `url_sources.py`
  - 站点 URL 常量源。
- `url_defaults.py`
  - 组装默认 URL 字典。
- `url_config_loader.py`
  - 读取 `assets/url_params.xlsx|json` 并转成可覆盖配置。
- `url_args_override.py`
  - 将外部配置覆盖到 argparse 对象。
- `url_key_aliases.py`
  - 友好 key 到 `argparse dest` 的别名映射与白名单。

### 3.3 抓取与抽取

- `bank_fetch_and_extract.py`
  - 抓取总入口，组织各站点提取并返回统一 payload。
- `bank_constants.py`
  - 抓取/表结构共享常量（列名、UA、通用值）。

### 3.4 Excel 产出

- `bank_excel_data_builder.py`
  - payload -> DataFrame（列重命名、列顺序、缺省补齐）。
- `bank_excel_template_writer.py`
  - 基于模板写入（sheet 管理、写入区、外币挂牌过滤）。
- `bank_excel_style_helpers.py`
  - openpyxl 样式工具（底色、居中、边框）。
- `bank_output_stage.py`
  - 输出阶段统一处理（写 Excel / 写 JSON / 控制 stdout）。

### 3.5 彩虹表

- `generate_rainbow_from_bank.py`
  - 从 MarketRateData 回填彩虹表模板：
    - 自动识别来源文件
    - 匹配银行与金额区间
    - 回填促销/挂牌利率并上色

### 3.6 资源与脚本

- `assets/MarketRateData_template.xlsx`
  - MarketRateData 模板（表头、布局、样式基线）。
- `assets/url_params.xlsx` / `assets/url_params.json`
  - URL 配置示例与默认配置。
- `01_首次安装依赖.bat`
  - 新机器依赖安装。
- `02_一键生成Excel.bat`
  - 一键生成 MarketRateData。
- `03_一键生成Market+彩虹表.bat`
  - 一键生成 MarketRateData + 彩虹表。

## 4) 3 条定位口诀（维护时最省时间）

1. 改“来源”（URL/参数）先看 `url_*` 和 `bank_cli_*`，再看 `bank_all_promo_rates.py` 是否接上。
2. 改“抓取解析”先看 `bank_fetch_and_extract.py`，改完马上核对 payload 是否仍能被 `bank_excel_data_builder.py` 消化。
3. 改“最终展示”先看模板 `assets/MarketRateData_template.xlsx` 与 `bank_excel_template_writer.py` 的写入规则是否一致。

## 5) 逐脚本“新增/删除”操作指引（可直接照做）

> 约定：下面“新增”默认指新增银行、字段、规则或参数；“删除”默认指下线银行、移除字段、移除规则。  
> 原则：**先断引用，再删实现**；删完至少跑一次全链路。

### `market_rate_data_generator.py`

- 新增
  - 一般不需要改；仅在你新增了新的总入口函数时，补一个调用分支。
- 删除
  - 若删入口分支，先确认没有 `.bat` 脚本或外部流程仍调用它。

### `generate_rainbow_from_market.py`

- 新增
  - 一般不需要改；仅在彩虹流程拆分新入口时添加调用。
- 删除
  - 删除前确认没有批处理脚本或定时任务依赖该入口。

### `bank_all_promo_rates.py`

- 新增
  - 若新增流程阶段（如新输出格式），在主流程中串接：参数解析 -> 处理 -> 输出。
  - 若新增 URL 参数链路，确认这里能拿到覆盖后的参数对象。
- 删除
  - 删除阶段前，先在下游模块确认无反向依赖（特别是输出阶段调用）。
  - 删除后检查主流程仍能完整走到产物落盘。

### `bank_cli_parser.py`

- 新增
  - 增加新的 CLI 参数（命名与 `dest` 统一），补 help 文案。
  - 建议命名规则：`--xxx-yyy` 对应 `dest=xxx_yyy`。
- 删除
  - 先全局搜索该 `dest` 的使用，再删参数定义。
  - 同步删除 `bank_cli_fetch_params.py` 的映射项，避免残留死代码。

### `bank_cli_fetch_params.py`

- 新增
  - 把新增的 argparse 字段映射到 `fetch_and_extract()` 关键字参数。
  - 保证参数名与 `fetch_and_extract()` 函数签名一致。
- 删除
  - 先删映射，再删函数签名和调用点，避免 `unexpected keyword` 或缺参错误。

### `bank_cli_url_config_applier.py`

- 新增
  - 新 URL 配置项要支持时，确认该文件会把配置覆盖到 argparse 对象。
- 删除
  - 删除覆盖逻辑前，确认是否仍需要 `--url-config` 机制；否则会导致配置文件失效。

### `bank_xlsx_out_resolver.py`

- 新增
  - 新命名规则放这里集中处理（日期、后缀、目录策略）。
- 删除
  - 删除规则分支时，确保默认路径仍可写且不覆盖关键文件。

### `url_sources.py`

- 新增
  - 增加内置默认 URL 常量（仅做默认值，不含业务逻辑）。
- 删除
  - 先确认该 URL 是否还被 `url_defaults.py` 引用，再删除常量。

### `url_defaults.py`

- 新增
  - 在 `get_url_defaults()` 中加入新 `dest` 对应默认 URL。
- 删除
  - 删除默认项前确认：CLI、外部配置、抓取函数签名是否同步移除该项。

### `url_config_loader.py`

- 新增
  - 若新增配置文件字段格式，先在这里补解析逻辑与类型兜底。
- 删除
  - 删除兼容分支前确认历史配置文件是否仍需兼容。

### `url_args_override.py`

- 新增
  - 新配置键要可覆盖时，在此增加覆盖映射处理。
- 删除
  - 删除覆盖键时，同步更新文档与示例配置，避免“配置写了不生效”。

### `url_key_aliases.py`

- 新增
  - 新增友好 key -> `dest` 映射。
  - 同步加入允许覆盖白名单（如有白名单机制）。
- 删除
  - 先删 alias，再删 `dest`，最后删上游配置键，避免半断链状态。

### `bank_fetch_and_extract.py`

- 新增
  - 给 `fetch_and_extract()` 增加新参数，接入请求与提取函数调用。
  - 返回 payload 必须保持既有结构约定（字段名、列表层级、类型）。
- 删除
  - 先从主流程移除该站点调用，再删提取分支与参数签名。
  - 删除后检查：空数据时是否仍有安全兜底。

### `bank_constants.py`

- 新增
  - 统一新增列名、通用字符串、请求相关常量，避免散落硬编码。
- 删除
  - 先搜索常量引用，再删定义；避免运行时 `NameError`。

### `bank_excel_data_builder.py`

- 新增
  - 新 payload 字段要在这里映射到 DataFrame 列，并补缺省值策略。
  - 列顺序必须与模板写入预期一致。
- 删除
  - 删字段前先确认模板已移除对应列，避免写表错位。
  - 删除过滤规则时，确认不会把无效行写入模板区域。

### `bank_excel_template_writer.py`

- 新增
  - 新 sheet/新写入区/新币种规则在此实现（起始行、覆盖范围、清理规则）。
- 删除
  - 删 sheet 逻辑前，确认模板中对应页签是否也已删除。
  - 删过滤逻辑前，确认不会影响既有“只保留有效记录”的产出质量。

### `bank_excel_style_helpers.py`

- 新增
  - 新样式函数集中加在这里，再由 writer 调用。
- 删除
  - 删除样式函数前先移除调用，避免导入或运行时报错。

### `bank_output_stage.py`

- 新增
  - 新输出形态（如 JSON 扩展、日志文件）统一在这里编排。
- 删除
  - 删除输出分支前，确认命令行开关和调用入口同步下线。

### `generate_rainbow_from_bank.py`

- 新增
  - 新模板结构、新匹配策略、新上色规则在这里加。
  - 优先复用既有匹配函数，减少模板耦合。
- 删除
  - 先下线调用，再删匹配函数；保留基础回填主干。
  - 删除后至少用一个历史样例验证“可匹配、可回填、可保存”。

### `bank_safety.py`

- 新增
  - 新异常类型或降级策略在这里统一加，避免每个模块散写 `try/except`。
- 删除
  - 删除兜底策略前评估失败影响范围，避免单点异常导致全流程中断。

### `assets/MarketRateData_template.xlsx`

- 新增
